# IT Security Digest

AI-сервис для автоматического создания персонального дайджеста новостей в области IT и информационной безопасности.

Сервис собирает публикации из выбранных источников, анализирует их с помощью GigaChat с учётом интересов пользователя, отбирает релевантные материалы, распределяет их по темам и формирует готовый дайджест в форматах Markdown и DOCX.

## Возможности

* Сбор публикаций из нескольких источников.
* Выбор источников пользователем.
* Настройка интересов пользователя.
* AI-анализ публикаций с помощью GigaChat.
* Определение релевантности статьи интересам пользователя.
* Определение темы и важности публикации.
* Краткое AI-описание каждой выбранной статьи.
* Группировка публикаций по темам.
* Ссылки на оригинальные публикации.
* Формирование дайджеста в Markdown.
* Формирование дайджеста в DOCX.
* Отображение процесса формирования дайджеста в веб-интерфейсе.
* Просмотр результата непосредственно в браузере.


Для каждой публикации AI определяет:

* является ли она релевантной выбранным интересам;
* к какой теме она относится;
* насколько она важна;
* краткое содержание;
* почему публикация была выбрана.

## Установка

### 1. Скачать проект

Клонируйте репозиторий:

```powershell
git clone (https://github.com/AshAgain/it-security-digest.git)
```

Перейдите в директорию проекта:

```powershell
cd it-security-digest
```

Если проект уже был скачан другим способом, достаточно перейти в его директорию:

```powershell
cd C:\Users\<имя_пользователя>\it-security-digest
```

### 2. Создать файл `.env`

В корне проекта находится файл `.env.example`.

Создайте на его основе файл `.env`.

В Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

После этого в корне проекта должны находиться:

```text
.env
.env.example
```

Файл `.env` используется для локальной конфигурации и не должен добавляться в Git.

### 3. Настроить `.env`

Откройте `.env` и проверьте настройки PostgreSQL:

```env
APP_NAME=IT Security Digest API
APP_VERSION=0.1.0
DEBUG=true

POSTGRES_DB=it_security_digest
POSTGRES_USER=digest_user
POSTGRES_PASSWORD=change_me
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

Пароль `POSTGRES_PASSWORD` можно изменить на любой удобный пароль.

GigaChat credentials можно использовать непосредственно через веб-интерфейс при формировании дайджеста.

### 4. Запустить PostgreSQL

Запустите PostgreSQL через Docker Compose:

```powershell
docker compose up -d
```

Проверьте состояние контейнера:

```powershell
docker compose ps
```

PostgreSQL должен иметь состояние `Up` и пройти healthcheck.

При необходимости посмотреть логи:

```powershell
docker compose logs postgres
```

### 5. Создать виртуальное окружение Python

Если виртуальное окружение ещё не создано:

```powershell
python -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

После активации в терминале должно появиться:

```text
(.venv)
```

### 6. Установить зависимости

Установите проект и его зависимости:

```powershell
python -m pip install --upgrade pip
pip install -e .
```

Для установки также зависимостей для разработки и тестирования:

```powershell
pip install -e ".[dev]"
```

### 7. Выполнить миграции базы данных

После запуска PostgreSQL выполните:

```powershell
alembic upgrade head
```

Команда создаст необходимые таблицы в базе данных.

### 8. Запустить приложение

Запустите FastAPI:

```powershell
uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000
```

Откройте этот адрес в браузере.

## Использование

После открытия веб-интерфейса необходимо:

### 1. Ввести GigaChat credentials

Для работы сервиса необходим ключ авторизации GigaChat API.

Ключ нужен для того, чтобы приложение могло отправлять запросы к моделям GigaChat и получать результаты AI-анализа публикаций.

В данном проекте используется авторизация для физических лиц (GIGACHAT_API_PERS).

Важно: вам нужен именно ключ авторизации (Authorization key), а не временный access token. Приложение самостоятельно использует ключ для получения необходимого токена доступа.

Шаг 1. Откройте страницу GigaChat API

Перейдите в официальный раздел документации GigaChat для физических лиц:

GigaChat API — быстрый старт для физических лиц

На этой странице описана актуальная процедура регистрации и создания проекта для работы с API.

Шаг 2. Войдите в личный кабинет

Для использования GigaChat API необходимо иметь аккаунт, с помощью которого можно войти в личный кабинет разработчика.

Если у вас уже есть аккаунт GigaChat / Sber ID, используйте его для входа.

Если аккаунта нет, зарегистрируйте его в соответствии с инструкциями на сайте GigaChat.

После авторизации перейдите к разделу, связанному с GigaChat API и проектами API.

Шаг 3. Создайте проект GigaChat API

Для работы с API необходимо создать отдельный проект.

Проект нужен для управления доступом к API и просмотра статистики использования.

В личном кабинете найдите возможность создания проекта GigaChat API.

Создайте новый проект и укажите необходимые параметры, которые запрашивает интерфейс.

После создания проекта откройте страницу созданного проекта.

Шаг 4. Найдите ключ авторизации

В настройках созданного проекта найдите раздел, связанный с API-ключом или авторизацией.

Вам нужен:

Authorization key

или

Ключ авторизации

Скопируйте этот ключ.

### 2. Выбрать интересы

Можно выбрать интересующие направления, например:

* Python
* Linux
* кибербезопасность
* уязвимости
* AI
* LLM
* Docker
* DevSecOps

### 3. Выбрать источники

Сервис поддерживает следующие источники:

* BleepingComputer
* Schneier on Security
* Microsoft Security Response Center

### 4. Запустить формирование

Нажмите кнопку:

```text
Сформировать дайджест
```

После запуска сервис:

1. собирает публикации;
2. анализирует статьи;
3. определяет релевантные материалы;
4. группирует их по темам;
5. формирует Markdown и DOCX;
6. отображает результат в браузере.

Во время работы отображается прогресс выполнения.

## Результат

После завершения формирования пользователь получает статистику:

* количество найденных публикаций;
* количество проанализированных публикаций;
* количество релевантных публикаций;
* количество нерелевантных публикаций.

Затем статьи отображаются сгруппированными по темам.

Для каждой статьи показываются:

* название;
* источник;
* дата публикации;
* тема;
* важность;
* краткое содержание;
* причина выбора;
* ссылка на оригинальную публикацию.

Также доступны кнопки для скачивания:

```text
Скачать Markdown
Скачать DOCX
```

## Изменение интересов

Одной из основных возможностей проекта является изменение результата в зависимости от интересов пользователя.

Например, можно сначала выбрать:

```text
Python
Docker
Linux
```

сформировать дайджест, а затем изменить интересы:

```text
AI
LLM
уязвимости
кибербезопасность
```

и сформировать его повторно.

При изменении интересов статьи анализируются с новым набором критериев, поэтому итоговая подборка может измениться.

## Основные компоненты

### `app/main.py`

Основное FastAPI-приложение.

Отвечает за:

* веб-интерфейс;
* API формирования дайджеста;
* отслеживание состояния задачи;
* скачивание Markdown;
* скачивание DOCX.

### `app/services/article_collector.py`

Собирает публикации из выбранных источников.

### `app/services/article_analyzer.py`

Передаёт публикации в GigaChat и сохраняет результаты анализа.

### `app/services/article_selector.py`

Выбирает актуальные публикации из базы данных.

### `app/services/digest_service.py`

Объединяет основные этапы формирования дайджеста в единый pipeline:

```text
Сбор
  ↓
Получение статей
  ↓
AI-анализ
  ↓
Отбор
  ↓
Группировка
  ↓
Генерация
```

### `app/services/digest_generator.py`

Формирует Markdown-версию дайджеста.

### `app/scripts/generate_digest_docx.py`

Формирует DOCX-версию дайджеста.

### `app/services/digest_task_manager.py`

Хранит состояние текущей задачи и позволяет веб-интерфейсу отображать прогресс.

## API

### Health check

```http
GET /health
```

Пример ответа:

```json
{
  "status": "ok"
}
```

### Создание дайджеста

```http
POST /api/digest
```

Тело запроса содержит:

```json
{
  "credentials": "GigaChat credentials",
  "interests": [
    "Python",
    "Linux",
    "AI"
  ],
  "sources": [
    "BleepingComputer",
    "Schneier on Security"
  ]
}
```

API возвращает идентификатор задачи:

```json
{
  "task_id": "..."
}
```

После этого клиент получает состояние задачи через:

```http
GET /api/digest/status/{task_id}
```

## Частые проблемы

### PostgreSQL не запускается

Проверьте:

```powershell
docker compose ps
```

Если контейнер остановлен, запустите:

```powershell
docker compose up -d
```

Посмотреть логи:

```powershell
docker compose logs postgres
```

### Ошибка подключения к PostgreSQL

Убедитесь, что PostgreSQL запущен и доступен на порту:

```text
localhost:5432
```

Также проверьте значения:

```env
POSTGRES_DB
POSTGRES_USER
POSTGRES_PASSWORD
POSTGRES_HOST
POSTGRES_PORT
```

в `.env`.

### Таблицы базы данных отсутствуют

Выполните:

```powershell
alembic upgrade head
```

### Приложение не запускается после создания виртуального окружения

Убедитесь, что виртуальное окружение активировано:

```powershell
.\.venv\Scripts\Activate.ps1
```

В начале строки терминала должно отображаться:

```text
(.venv)
```

Затем повторите:

```powershell
pip install -e .
```

### Не формируется дайджест

Сначала проверьте PostgreSQL:

```powershell
docker compose ps
```

Затем убедитесь, что приложение запущено:

```powershell
uvicorn app.main:app --reload
```

Также проверьте правильность GigaChat credentials, введённых в веб-интерфейсе.

## Безопасность

Файл `.env` содержит локальные настройки и секретные данные и не должен публиковаться в Git.

Не добавляйте реальные GigaChat credentials в:

* Git;
* GitHub;
* README;
* исходный код;
* публичные issue или сообщения.

Для демонстрации ключ вводится непосредственно через веб-интерфейс.
